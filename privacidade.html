Política de Privacidade

Aplicativo “Animador JJ - Claude” · Última atualização: 17 de novembro de 2026

1. Quem somos e para quem é o aplicativo

“Animador JJ - Claude” é um programa de uso próprio, operado por Animador JJ, que roda no computador Windows do responsável. Ele é usado somente pelo dono dos canais, para os canais do YouTube que ele mesmo autoriza. Não há cadastro de usuários, site de serviço nem servidor próprio: tudo acontece no computador do responsável e nas APIs oficiais do Google.

2. Dados do Google que o aplicativo acessa

O acesso só acontece depois que o dono do canal entra na tela oficial do Google (accounts.google.com) e autoriza. Permissões (escopos) pedidas:

PermissãoPara que é usada
youtube.uploadEnviar ao canal os vídeos produzidos pelo dono, como privados, com título, descrição e miniatura.
youtube.readonlyLer o nome e o ID do canal (para confirmar que é o canal certo) e a lista de vídeos do canal: título, situação (público, privado, programado), data de envio, data programada e duração. Serve para escolher a próxima data livre e para não enviar o mesmo vídeo duas vezes.
youtubeSomente para programar a data de publicação de vídeos privados do próprio canal que ainda não têm data. O aplicativo não usa essa permissão para apagar vídeos, comentar, alterar outros dados ou acessar outros canais.
yt-analytics.readonlyLer estatísticas do próprio canal (visualizações, tempo assistido, duração média, retenção, curtidas, comentários, compartilhamentos, inscritos ganhos) para o dono analisar o desempenho dos seus vídeos. Somente leitura.

O aplicativo não pede nem acessa e-mail, contatos, Gmail, Drive ou qualquer outro dado da conta Google.

4. Compartilhamento

O aplicativo não vende, não aluga, não compartilha e não transfere dados de usuários do Google a ninguém. Os dados não são usados para publicidade, perfis de usuários ou treinamento de modelos de inteligência artificial.

5. Uso Limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Por quanto tempo e como apagar

  • A autorização fica guardada até o responsável desconectar o canal. O comando de desconexão do programa apaga do computador as autorizações guardadas.
  • A qualquer momento o dono da conta pode revogar o acesso em myaccount.google.com/permissions. Depois disso o aplicativo não consegue mais acessar o canal.
  • Os registros (CSV, texto, JSON) ficam no computador do responsável até ele apagá-los; basta excluir os arquivos.
  • Os vídeos enviados ficam no próprio canal do YouTube e são gerenciados pelo dono no YouTube Studio.

7. Facebook (integração separada)

O mesmo programa pode, em separado, enviar vídeos às Páginas do Facebook do responsável pela API oficial da Meta. Nesse caso, guarda somente o ID e a chave do app da Meta e os tokens das Páginas autorizadas, criptografados da mesma forma (DPAPI) no computador do responsável. Nenhum dado do Google é enviado à Meta, e nenhum dado da Meta é enviado ao Google.

8. YouTube e Google

Este aplicativo usa os YouTube API Services. Consulte também a Política de Privacidade do Google e os Termos de Serviço do YouTube.

English version

Animador JJ - Claude is a personal tool operated by Animador JJ that runs on the operator's own Windows computer and is used only for the YouTube channels the operator authorizes through Google's official sign-in page. There is no public sign-up and no server of its own.

Google data accessed and why: youtube.upload — upload the operator's videos as private, with title, description and thumbnail; youtube.readonly — read the channel name/ID (to confirm the right channel) and the channel's video list (title, privacy status, upload date, scheduled date, duration) to choose free publishing dates and avoid duplicate uploads; youtube — only to set the scheduled publish date of the channel's own private videos that have no date yet (never used to delete videos, comment, or access other channels); yt-analytics.readonly — read the channel's own statistics so the operator can review performance. No email, contacts or other Google account data is requested.

Storage: refresh tokens and the OAuth client identifier are stored only on the operator's computer, encrypted with Windows Data Protection (DPAPI). Access tokens are kept in memory only. Local CSV/text/JSON records (dates, channel, title, file name, video ID, scheduled date/time, status, analytics figures) contain no tokens; tokens are stripped from logs. No Google user data is sent to any server other than Google's own APIs.

Sharing: Google user data is not sold, rented, shared or transferred, and is not used for advertising, profiling or AI model training. The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion: authorizations are kept until the operator disconnects the channel (the app's disconnect command deletes them) or revokes access at myaccount.google.com/permissions. Local records stay on the operator's computer until deleted. Uploaded videos remain in the operator's YouTube channel.

Facebook: a separate integration may upload videos to the operator's Facebook Pages through Meta's official API, storing only the Meta app ID/secret and Page tokens, DPAPI-encrypted, on the operator's computer. Google data is never sent to Meta.

This app uses YouTube API Services; see the Google Privacy Policy and the YouTube Terms of Service. Contact: jonasjj5070@gmail.com.
