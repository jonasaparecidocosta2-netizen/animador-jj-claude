Animador JJ - Claude

Ferramenta pessoal de automação de publicações para os canais do YouTube do próprio dono.

Política de Privacidade Termos de Serviço English

O que é

“Animador JJ - Claude” é um programa de uso próprio que roda no computador do dono dos canais (Windows). Ele usa a API oficial do YouTube (YouTube API Services) para cuidar apenas dos canais que o próprio dono autoriza na tela oficial de login do Google. Não é um serviço aberto ao público, não tem cadastro e não tem servidor próprio.

O que ele faz

  • Envia vídeos produzidos pelo dono para o canal autorizado, como privados, com título, descrição e miniatura.
  • Programa a data de publicação dos vídeos privados do canal, para que o YouTube os torne públicos na data escolhida pelo calendário do dono.
  • Lê a lista de vídeos do canal (título, situação e datas) para escolher datas livres e não enviar o mesmo vídeo duas vezes.
  • Lê estatísticas do canal (YouTube Analytics, somente leitura) para o dono analisar o desempenho dos próprios vídeos.

O programa não comenta, não apaga vídeos, não acessa canais de outras pessoas e não vende nem compartilha dados. Detalhes em Política de Privacidade.

English

Animador JJ - Claude is a personal automation tool that runs on the channel owner's own Windows computer. It uses the official YouTube API Services only for the YouTube channels the owner authorizes on Google's official sign-in page. It uploads the owner's videos as private (title, description, thumbnail), sets the scheduled publish date of the owner's private videos, reads the channel's video list (titles, status, dates) to pick free dates and avoid duplicates, and reads YouTube Analytics (read-only) so the owner can review their own channel's performance. It has no public sign-up and no server of its own. See the Privacy Policy and Terms of Service. Contact: jonasjj5070@gmail.com.
